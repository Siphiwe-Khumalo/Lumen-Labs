# Lumen Labs Apparel Concept

Preliminary typographic embroidery concept for a heavyweight black or graphite T-shirt. This is concept artwork and must not be treated as an official logo or a machine-ready embroidery file.

## Exports

- `exports/lumen-labs-front-mockup.png` — front-view garment mockup, 2400 × 3000 px.
- `exports/lumen-labs-wordmark-transparent.png` — isolated transparent wordmark, 2400 × 560 px.

## Direction

- Placement: wearer’s left chest
- Intended embroidery width: approximately 72 mm
- Thread palette: warm amber for “Lumen” and soft off-white for “Labs”
- Garment: 100% heavyweight cotton, approximately 220–260 GSM
- Fit: regular to slightly relaxed

The SVG and PNG files are visual artwork only, not DST/PES embroidery files. A professional embroidery digitizer should convert the outlined artwork, confirm stitch density and underlay, and run a physical sew-out before production.
