# Lumen Labs Creatives — Founder Assets

Founder banner and transparent founder graphic for **Ronnie — Founder, Lumen Labs Creatives**.

These assets use the same visual identity already live on the Lumen Labs
website and in the rest of the `brand/` pack:

- Graphite ink `#06080a`
- Warm lumen gold `#e9b978`
- Cool technical steel `#a9c8d8`
- Off-white text `#f3f2ee`
- Space Grotesk for the display name
- JetBrains Mono for technical labels and metadata
- Manrope for the supporting line
- The actual `BrandMark` geometry from `src/components/brand/Logo.tsx`
- Faint drafting rules, hairline framing, and restrained liquid-light treatment

## Files

| File | Use | Size |
|---|---|---:|
| `Lumen-Labs-Founder-Banner.png` | Wide horizontal banner for LinkedIn, social headers, or the website | 2376 × 594 px |
| `Lumen-Labs-Founder-Transparent.png` | Standalone transparent founder graphic for placing over other backgrounds | 1800 × 2250 px |
| `Lumen-Labs-Founder-Banner.svg` | Editable vector/layout source for the wide banner | 1584 × 396 SVG units |
| `Lumen-Labs-Founder-Transparent.svg` | Editable vector/layout source for the transparent graphic | 1200 × 1500 SVG units |

The PNGs are the ready-to-use exports. The SVGs keep the typography, mark,
frame, accent rules, and layout editable in Figma, Illustrator, Inkscape, or
a browser. The portrait is embedded as a raster image inside the SVG source,
so it remains portable without an external image path.

## Portrait treatment

The supplied founder photo was used as the source. Its background was removed,
a bright mirror-frame artifact near the left side of the head was cleaned
manually, the framing was tightened to a face-and-shoulders portrait so the
phone does not dominate the composition, and the image was subtly cooled and
desaturated to sit naturally against Lumen Labs' graphite technical palette.
No replacement face, generated person, or invented portrait was used.

## Editing notes

The SVG files preserve editable layout elements and text. If the name,
role, supporting line, or website changes, edit the corresponding SVG text
nodes and re-export the PNG. Keep the brand token values unchanged unless the
website design system is intentionally updated first.
