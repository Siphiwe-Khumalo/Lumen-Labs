## Replacing imagery

Swap the file in place and keep the filename, or update the import in `src/data/projects.ts` / `src/data/services.ts`. Remove the `imageNote` value on a project only once the image is genuinely from that project and approved for publication.

Content was rephrased for compliance with licensing restrictions.
